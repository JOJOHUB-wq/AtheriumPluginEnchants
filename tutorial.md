### Краткое руководство по AtheriumEnchants

#### 1. Как скомпилировать плагин

Для компиляции плагина вам понадобится Apache Maven.

1.  **Откройте терминал или командную строку** в корневой папке проекта (где находится файл `pom.xml`).
2.  **Выполните команду:**
    ```bash
    mvn clean package
    ```
3.  Maven автоматически скачает все зависимости и соберет плагин.
4.  Готовый `.jar` файл будет находиться в папке `target/`. Ищите файл с названием типа `AtheriumEnchants-1.0-SNAPSHOT.jar`.
5.  Переместите этот файл в папку `plugins` вашего сервера.

#### 2. Как настроить зачарования (`enchants.yml`)

##### а) Изменение целей для `blast_mining` (Бульдозер)

Зачарование `blast_mining` может ломать только определенные блоки, в зависимости от инструмента в руке. Это сделано для предотвращения грифа (например,скапывание чужих построек киркой).

-   Найдите секцию `blast_mining` в `enchants.yml`.
-   Внутри нее есть блок `tool-targets`.
-   Списки `PICKAXE`, `SHOVEL`, `AXE` содержат материалы блоков, которые можно ломать соответствующим инструментом.
-   **Пример:** Чтобы разрешить Бульдозеру на кирке ломать землю, добавьте `DIRT` в список `PICKAXE`:

```yaml
tool-targets:
  PICKAXE:
    - STONE
    - COBBLESTONE
    # ... (другие блоки)
    - DIRT # <--- Добавлено
```

##### б) Добавление нового зачарования на эффектах зелий

Создать новое зачарование, которое накладывает эффект зелья (как `toxic` или `vampirizm`), очень просто.

1.  **Скопируйте** существующий блок, например, `toxic`.
2.  **Измените ключ** (например, на `withering_strike`).
3.  **Заполните основную информацию:** `display_name`, `description`, `rarity`, `max_level`, `applies_to` и т.д.
4.  **Настройте блок `effect`:**
    *   `type`: Оставьте `"POTION"`.
    *   `target`: `VICTIM` (на цель) или `SELF` (на себя).
    *   `chance`: Шанс срабатывания в процентах.
    *   `potion-type`: Название эффекта из Bukkit (например, `WITHER`, `SLOW`, `BLINDNESS`).
    *   `duration-ticks`: Длительность в тиках (20 тиков = 1 секунда).
    *   `amplifier`: Уровень эффекта (0 = I, 1 = II, и т.д.).

**Пример нового зачарования "Иссушающий Удар":**

```yaml
withering_strike:
  enabled: true
  display_name: "&#5A5A5AИссушающий Удар"
  description:
    - "&fШанс наложить эффект иссушения."
  rarity: "EPIC"
  max_level: 2
  conflicts: []
  applies_to: [ SWORD ]
  enchanting_table:
    enabled: true
    chance_weight: 4
  trigger: "ATTACK_ENTITY"
  effect:
    type: "POTION"
    target: "VICTIM"
    level-1:
      chance: 20.0
      potion-type: "WITHER"
      duration-ticks: 100 # 5 секунд
      amplifier: 0
    level-2:
      chance: 30.0
      potion-type: "WITHER"
      duration-ticks: 140
      amplifier: 1 # Иссушение II
```

#### 3. Как работает система синергии (без дюпов)

Ключ к правильной работе синергии — это централизованное управление дропом в классе `GlobalEnchantListener`.

1.  **Перехват события:** Когда игрок ломает блок (`BlockBreakEvent`), слушатель **приостанавливает** стандартный дроп (`event.setDropItems(false)`).
2.  **Сбор основного дропа:** Дроп с первого сломанного блока помещается в специальный "мастер-список" (`masterDrops`).
3.  **Поочередное выполнение:**
    *   Сначала срабатывают чары, **увеличивающие количество блоков** (Бульдозер, Лесоруб). Они добавляют дроп со всех дополнительных блоков в тот же `masterDrops`. На этом этапе корректно применяется ванильная Удача (Fortune), так как она рассчитывается в момент получения дропа с блока.
    *   Затем этот `masterDrops` передается следующему зачарованию, например, **Авто-плавке** (`SmeltEffect`). Оно не добавляет новые предметы, а **модифицирует существующие** (заменяет `RAW_IRON` на `IRON_INGOT` прямо в списке).
    *   Наконец, финальный, измененный `masterDrops` передается **Магниту** (`TelekinesisEffect`). Он не меняет список, а просто пытается добавить все предметы из него в инвентарь игрока.
4.  **Предотвращение дюпа:** Так как стандартный дроп отменен, а все зачарования работают с **одним и тем же списком по цепочке**, дубликация предметов исключена. Плагин полностью контролирует, какие предметы и в каком виде получит игрок в самом конце.
